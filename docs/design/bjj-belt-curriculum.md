## WHITE BELT — Learn the Basic Game

**Goal.** Understand what is happening in a BJJ match and have a basic answer
from every major position. The white belt should focus on position, safety,
escapes, and a small number of dependable techniques.

### 1. Start Standing
Learn how to safely begin an exchange.
- Proper grappling stance
- Base and balance
- Grip fighting basics
- Hand fighting
- Breakfalls
- Technical stand-up
- Sprawl

### 2. Get the Fight to the Ground
Know a few simple ways to initiate.
- Double leg takedown
- Single leg takedown
- Body lock + outside trip
- Basic foot sweep
- Snapdown
- Safe guard pull

*The goal is not to know ten takedowns. A white belt should have 2–3 takedowns
they understand well.*

### 3. Understand Guard
Learn what guard is and why it matters.

**Bottom**
- Closed guard
- Basic open guard
- Half guard
- Butterfly guard introduction

**Understand**
- Keep opponent between your legs
- Control distance
- Break posture
- Protect yourself
- Create angles

### 4. Sweep From Bottom
Learn how to get from bottom to top. Fundamental sweeps:
- Scissor sweep
- Hip bump sweep
- Flower / pendulum sweep
- Tripod sweep
- Butterfly sweep
- Half guard underhook sweep

*The important concept: if you cannot submit safely, improve position.*

### 5. Pass the Guard From Top
Understand that before attacking, you usually need to get past the legs.
Fundamental passes:
- Standing closed guard opening
- Knee cut
- Toreando
- Double under pass
- Over-under pass
- Basic half guard pass

*Main concept: legs → hips → shoulders → control.*

### 6. Establish Side Control
Learn how to actually hold someone after passing.
- Crossface
- Underhook
- Hip control
- Chest-to-chest pressure
- Prevent guard recovery

**Basic transitions**
- Side control → mount
- Side control → knee-on-belly
- Side control → back exposure

**Basic submissions**
- Americana
- Kimura
- Armbar
- Arm triangle

### 7. Establish Mount
Learn to stabilize before attacking.
- Low mount
- High mount
- Technical mount
- Maintaining mount during bridging

**Fundamental attacks**
- Americana
- Arm triangle
- Cross-collar choke
- Ezekiel
- Armbar

### 8. Take and Control the Back
Understand why the back is one of the strongest positions.
- Seatbelt
- Hooks
- Chest-to-back connection
- Head position
- Following opponent during escape

**Fundamental finish**
- Rear naked choke

**Gi**
- Basic collar choke

### 9. Turtle
Know what to do from both sides.

**Bottom**
- Protect neck
- Protect hooks
- Sit-out
- Granby / re-guard
- Return to guard
- Stand up

**Top**
- Seatbelt
- Spiral ride
- Insert hooks
- Take the back

### 10. Escape Bad Positions
One of the most important white belt areas.

**Mount** — trap-and-roll · elbow escape
**Side control** — frame + shrimp · underhook escape · recover guard
**Back** — protect neck · two-on-one grip · remove hooks · get shoulders to the floor · turn into opponent
**Turtle** — protect neck · recover guard · stand

### 11. Submission Defense
Understand the danger before learning advanced attacks. Know basic defense
against: rear naked choke, guillotine, triangle, armbar, kimura, americana, arm
triangle, straight ankle lock.

### White belt fundamental flow

```
Standing → Takedown / Guard Pull → Guard → Sweep or Pass
  → Side Control → Mount / Back → Submission

If position is lost:
  Escape → Recover Guard / Get Top → Start attacking again
```

## BLUE BELT — Build Reliable Systems

**Goal.** Stop thinking only in individual techniques. Start understanding
*technique → opponent reaction → second technique*. A blue belt should begin
developing a real personal game.

### 1. Standing
Build reliable combinations: grip fighting, single leg, double leg, high crotch,
body lock, snapdown, arm drag, foot sweeps, guard pull attacks.

*Start chaining:* single leg → opponent defends → double leg. Snapdown → front
headlock → go behind.

### 2. Guard Retention
Before becoming great at attacking guard, become difficult to pass.
- Frames
- Hip movement
- Inside position
- Leg pummeling
- Recovering from knee cut
- Recovering from toreando
- Recovering from leg drag
- Seated guard retention
- Supine guard retention

### 3. Build Two Guards
Start developing at least two connected guards. Examples: butterfly + half
guard; De La Riva + single leg X; collar sleeve + lasso; seated guard +
shin-to-shin.

### 4. Attack From Guard
Build combinations rather than isolated moves.
- **Closed guard** — triangle ↔ armbar ↔ omoplata
- **Butterfly** — butterfly sweep → arm drag → back take
- **Half guard** — underhook → dogfight → sweep → back take

### 5. Develop Passing Systems
**Movement passing** — toreando, knee cut, X-pass, leg drag
**Pressure passing** — over-under, body lock, double under, half guard pressure

*Start combining:* toreando → opponent recovers → knee cut → opponent blocks →
leg drag.

### 6. Control After Passing
Become better at preventing escapes. Connect side control → north-south →
knee-on-belly → mount → back, instead of holding one position forever.

### 7. Build Submission Chains
- **Mount** — arm triangle → opponent turns → back take → RNC
- **Side control** — kimura → armbar → back take
- **Back** — RNC → short choke → armbar

### 8. Front Headlock
Begin treating front headlock as a major attacking position: snapdown, chin
strap, go behind, guillotine, arm-in guillotine, darce, anaconda, back take.

### 9. Leg Locks
Understand the fundamental leg-lock game.
- **Positions** — straight ashi, single leg X, outside ashi, 50/50 introduction
- **Submission** — straight ankle lock
- **Most importantly** — knee line, control, safe escape, hand fighting

### 10. Improve Escapes
White belt escapes become combinations. Mount: elbow escape → opponent blocks →
bridge → opponent posts → recover half guard. The blue belt should understand
escape chains.

### Blue belt fundamental flow

```
Standing combination → Takedown / Guard Entry → Preferred Guard
  → Sweep / Submission / Wrestle-up → Passing System → Pin
  → Advance Position → Submission Chain → Opponent Escapes
  → Follow Them Into Another Attack
```

## PURPLE BELT — Connect the Entire Game

**Goal.** Stop seeing BJJ as separate positions. The question becomes: *what
reaction do I want my opponent to give me?*

### 1. Establish a Standing Game
Have a clear starting strategy. Grip fight → single leg → opponent sprawls →
front headlock → guillotine / back take. Or: guard pull → immediate sweep
attack. *A purple belt should rarely begin a match without knowing what they
want.*

### 2. Build an A-Game Guard
Choose a primary guard (butterfly, half guard, De La Riva, collar sleeve, lasso,
X guard, wrestle-up guard) and know: how to enter it, retain it, sweep, submit,
take the back, and what to do when the opponent shuts it down.

### 3. Build Guard Connections
Seated guard → shin-to-shin → single leg X → X guard → sweep. Or: De La Riva →
reverse DLR → kiss of the dragon → back take. *Move between guards naturally.*

### 4. Advanced Guard Retention
Recover during late-stage passes: leg pummeling, inversion, granby, turtle
recovery, high-leg recovery, half guard recovery, recovering against body lock,
recovering against leg drag.

### 5. Build a Passing Tree
Instead of knowing passes, create reactions. Knee cut → opponent blocks knee →
back step → opponent follows → leg drag → opponent turtles → back take.

### 6. Control Transitions
Move without giving space. Side control → north-south → kimura → opponent turns
→ back → opponent escapes back → mount. *BJJ becomes circular rather than
linear.*

### 7. Develop Submission Systems
- **Front headlock** — guillotine → darce → anaconda → back take
- **Kimura** — kimura → armbar → back take → triangle
- **Back** — RNC → rear triangle → armbar → mount

### 8. Leg Entanglement System
Guard → leg entanglement → submission, or sweep, or back take, or come on top.
*Positional leg locking, not just submissions.*

### 9. Scrambles and Wrestling
Wrestle-ups, front headlock, mat returns, single leg counters, scramble
awareness, turtle attacks, turtle recoveries. *Understand where the next
dominant position will appear.*

### 10. Strategy
Score, time, risk, energy, opponent's strengths, opponent's reactions.

### Purple belt fundamental flow

```
Create Preferred Starting Exchange → Force A-Game Position → Create Reaction
  → Opponent Defends → Transition to Secondary System → Pass / Sweep / Back Take
  → Control → Create Submission Dilemma → Opponent Escapes
  → Use Escape to Enter Next Position → Continue Chain
```

## BROWN BELT — Master Your Game

**Goal.** No longer about learning every technique — about making fundamental
BJJ extremely difficult to stop. Understand *why, when, where, and against whom*
a technique works.

### 1. Create a Complete Starting Strategy
Have answers for: wrestler, guard puller, bigger opponent, smaller opponent,
pressure player, flexible guard player, leg-lock player. Multiple ways to
dictate where the match happens.

### 2. Master Your Best Takedown System
A deep system around 2–3 rather than ten average takedowns. Single leg →
opponent sprawls → front headlock; opponent pulls leg away → double leg;
opponent whizzers → body lock; opponent turns → back take.

### 3. Master Your Primary Guard
Answers against every major passing style — when the opponent kneels, stands,
pressure passes, body locks, knee cuts, toreandos, back steps, leg drags,
attacks legs, or disengages.

### 4. Remove Guard Weaknesses
If primary guard fails → secondary guard → half guard → turtle → wrestle up →
return to top. *There should always be another layer.*

### 5. Master a Passing Philosophy
Understand *why* passes work — control feet, knees, hips, shoulders, head — with
a complete system against seated guard, supine guard, half guard, butterfly,
DLR, lasso, X guard, inverted guards, wrestle-up guards.

### 6. Master Pinning
Force defensive reactions rather than simply holding. Side control pressure →
opponent frames → north-south → opponent turns → take back. Or: mount →
opponent protects neck → separate elbow → armbar → opponent hides arm → gift
wrap → back take.

### 7. Develop Finishing Systems
- **Back** — RNC, short choke, rear triangle, armbar, mount transition
- **Mount** — arm triangle, armbar, triangle, back take
- **Front headlock** — guillotine, darce, anaconda, back take
- **Legs** — ankle lock, kneebar, toe hold, heel hook where appropriate, sweep, back take

### 8. Master Defensive Layers
Before control happens → during control → before submission isolation → during
submission → late-stage escape → counterattack. *The best defense is
increasingly preventative.*

### 9. Control Scrambles
Know when to scramble, stop scrambling, turtle, wrestle, sit to guard, attack
front headlock, chase the back, stabilize position.

### 10. Strategic Mastery
Where do I want this fight? What is my strongest path there? What is my opponent
likely to do? What is my answer? What happens if my first strategy fails?

### Brown belt fundamental flow

```
Control Initial Engagement → Force Preferred Position
  → Opponent Reacts Predictably → Enter A-Game System → Opponent Defends
  → Use Defense to Advance → Control Position → Create Multiple Threats
  → Finish
OR
  → Opponent Escapes → Immediately Reconnect to Another System → Repeat
```

## The simple progression

| Belt | What it is for |
|---|---|
| **White** | Learn the map. Standing → takedown → guard → sweep/pass → side control → mount/back → submission. And learn how to escape everything. |
| **Blue** | Build reliable routes through the map. Technique → reaction → second technique. Start developing your own game. |
| **Purple** | Connect the routes into systems. Attack → reaction → transition → reaction → another attack. Begin manipulating the opponent rather than responding. |
| **Brown** | Master and refine your personal system. Control where the fight happens, force predictable reactions, attack several options at once, use very little unnecessary movement, turn the opponent's defense into your next attack. |

**The core progression:** White — understand positions and survive. → Blue —
attack reliably from positions. → Purple — connect positions and reactions. →
Brown — control the entire decision tree.
